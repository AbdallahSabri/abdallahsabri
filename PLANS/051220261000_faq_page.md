# Plan: FAQ Page

**Date:** 2026-05-12

---

## Context

Add a standalone `/faq` page to the portfolio site. The page answers common visitor questions about availability, services, stack, rates, and process — reducing repetitive contact-form noise and improving discoverability via search (FAQPage schema). The page follows the same pattern as `/about` and `/projects`: its own route under `[locale]/`, a section component, full i18n (en + ar), metadata, and a JSON-LD FAQPage schema. FAQ items use an accordion (expand/collapse) — standard UX pattern for FAQ pages.

## Component Details

### `src/components/ui/Accordion.tsx`

- `"use client"` directive (needs `useState`)
- Props: `question: string`, `answer: string`
- Internal `useState<boolean>` for open/close toggle
- Button trigger shows question + chevron icon (rotates on open)
- Answer panel animates height or uses `max-h` Tailwind transition
- Styling: `border border-white/5`, `bg-[#18181b]`, `rounded-2xl`, `text-zinc-400`, `indigo-500` chevron

### `src/components/sections/FAQ.tsx`

- Server component (no `"use client"`)
- Props: `items: { id: string; question: string; answer: string }[]`
- Uses `getTranslations("FAQ")` for UI strings only (label, heading, description)
- Structure:
  ```
  <section id="faq">
    <SectionLabel>{t("label")}</SectionLabel>
    <h2>{t("heading")}</h2>
    <p>{t("description")}</p>
    {items.map(item => <Accordion key={item.id} question={item.question} answer={item.answer} />)}
  </section>
  ```
- Container: `mx-auto max-w-3xl` (narrower than grid sections — FAQ reads better in single column)

### `src/app/[locale]/faq/seo.ts`

```ts
export function getFAQSchema(items: { question: string; answer: string }[]) {
  return {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    mainEntity: items.map(({ question, answer }) => ({
      "@type": "Question",
      name: question,
      acceptedAnswer: { "@type": "Answer", text: answer },
    })),
  };
}
```

### `src/app/[locale]/faq/page.tsx`

- Receives `{ params: { locale } }` — use it to load the right content file
- Load items via direct JSON import map (static, tree-shaken at build time):
  ```ts
  import enItems from "@/../content/faq/en.json";
  import arItems from "@/../content/faq/ar.json";
  const itemsMap = { en: enItems, ar: arItems };
  const items = itemsMap[locale as "en" | "ar"];
  ```
- `generateMetadata()` — spreads `defaultMetadata`, overrides `title`, `description`, `openGraph.url`, `alternates.canonical` and `languages` (en/ar)
- Default export:
  1. Inject `<script type="application/ld+json">` with `getFAQSchema(items)`
  2. `<Navbar />`
  3. `<main><FAQ items={items} /></main>`
  4. `<Footer />`
  5. `<ScrollToTop />`

### `Navbar.tsx` change

Add one entry to `navLinks` after the `projects` entry:
```ts
{ label: t("links.faq"), href: "/faq", type: "page" },
```
