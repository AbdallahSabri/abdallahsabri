# Blog Module Plan

## Context

Adding a `/blog` section to the personal portfolio site. Posts are authored in MDX files, content is English-only (Arabic locale renders the same English content), and SEO must match the structured/thorough patterns already established for the projects module.

---

## Architecture Decisions

- **Content source:** MDX files in `/content/blog/[slug].mdx` with YAML frontmatter
- **Rendering:** `next-mdx-remote/rsc` (App Router Server Component compatible)
- **Frontmatter parsing:** `gray-matter`
- **Prose styling:** `@tailwindcss/typography` with a custom dark `prose` theme
- **Code highlighting:** `rehype-pretty-code` + `shiki` (dark theme matching site)
- **Locale:** English content served for both `/en/blog` and `/ar/blog`; `x-default` + canonical always point to `/en/...`

---

## Files to Create

### 1. Content directory
```
content/blog/
  └── my-first-post.mdx   # Seed post to validate the setup
```

**Frontmatter shape:**
```yaml
---
title: "Post Title"
date: "2026-05-12"
excerpt: "Short description shown in list and OG tags."
tags: ["Next.js", "TypeScript"]
readTime: "5 min read"
---
```

---

### 2. `src/lib/blog.ts` — Content utility

Functions:
- `getAllPosts()` → sorted array of post metadata (no content), newest first
- `getPostBySlug(slug)` → full post including raw MDX content string

Types:
```ts
type BlogPostMeta = { slug, title, date, excerpt, tags, readTime }
type BlogPost = BlogPostMeta & { content: string }
```

Reads from `content/blog/*.mdx` using `fs` + `gray-matter`.

---

### 3. `src/app/[locale]/blog/page.tsx` — List page

- `generateMetadata()` uses `getTranslations("Blog")` for title/description with hreflang alternates
- Pulls posts via `getAllPosts()` from `src/lib/blog.ts`
- Renders two JSON-LD schemas inline: `BreadcrumbList` + `CollectionPage`
- Layout: centered `max-w-3xl`, vertical list of post cards (title, date, excerpt, tags, read time, "Read article →")
- Card style mirrors projects: `bg-[#18181b]`, `border-white/5`, indigo accent on hover/CTA

---

### 4. `src/app/[locale]/blog/[slug]/page.tsx` — Post detail page

- `generateStaticParams()` returns all slugs (locale handled by parent layout)
- `generateMetadata()` builds per-post metadata from frontmatter (title, excerpt as description, OG, hreflang)
- Injects two schemas from `./seo.ts`: `BreadcrumbList` + `BlogPosting`
- Renders: `Navbar` → post header (title, date, tags, read time) → MDX content via `<MDXRemote>` → `Footer` → `ScrollToTop`
- MDX content wrapped in Tailwind `prose prose-invert` for dark-theme typography

---

### 5. `src/app/[locale]/blog/[slug]/seo.ts` — Per-post schemas

Dynamic function `getBlogSchemas(post: BlogPostMeta)` returns:
```ts
{
  breadcrumbSchema: BreadcrumbList  // Home → Blog → Post Title
  articleSchema: BlogPosting        // headline, datePublished, author @id, description
}
```

### `messages/ar.json`
Add matching `"Blog"` namespace in Arabic.

### `src/app/sitemap.ts`
Add blog routes using `getAllPosts()`:
- `/blog` (en + ar)
- `/blog/[slug]` (en + ar) for every post

### `src/app/globals.css`
Register `@tailwindcss/typography` plugin and add custom `prose` overrides for the dark zinc theme (links → indigo, headings → white, inline code → zinc-200 on zinc-800 background).

## SEO Structure

| Page | Schemas | Canonical | hreflang |
|---|---|---|---|
| `/blog` | BreadcrumbList, CollectionPage | `/en/blog` | en, ar, x-default |
| `/blog/[slug]` | BreadcrumbList, BlogPosting | `/en/blog/[slug]` | en, ar, x-default |

`generateMetadata()` pattern follows projects exactly — all fields built explicitly (title, description, openGraph, twitter, alternates).
